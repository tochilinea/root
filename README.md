Это закон Менкена:
Для каждой сложной задачи существует решение, которое является быстрым, простым и неправильным.

Пример:
У меня сайт тормозит, сделайте быстро и просто. Ты делаешь быстро и просто - ставишь chmod 777. Сайт летает... 10 минут, пока его не взломают.

**Не делай "быстро и просто" - делай чтобы работало!**
